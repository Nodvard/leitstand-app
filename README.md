# Nodvard Leitstand – Update-Prüfsummen

Hier steht nur `update.json` mit der aktuellen Version der Leitstand-App und der SHA-256-Prüfsumme ihrer `app.asar`. Die App holt das neue Paket vom Leitstand-Server und spielt es nur ein, wenn die Prüfsumme mit dieser Datei übereinstimmt. So kann auch ein übernommener Server keinen fremden Code auf den PC bringen.
